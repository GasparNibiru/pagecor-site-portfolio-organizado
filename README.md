# Pagecor Site Portfolio

Projeto organizado para abrir no VS Code e publicar pelo GitHub/Netlify.

## Estrutura

```
pagecor-site-portfolio-organizado/
├── index.html
├── assets/
│   └── images/
└── README.md
```

## Como usar

1. Abra esta pasta no VS Code.
2. Suba a pasta para um repositório no GitHub.
3. No Netlify, conecte o repositório e publique como site estático.

## Observação importante

Os nomes originais das imagens foram preservados. Apenas os caminhos no `index.html` foram ajustados para `assets/images/`, respeitando maiúsculas, minúsculas, espaços e acentos dos arquivos reais.
